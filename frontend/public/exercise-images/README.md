# Принятые изображения упражнений

134 полных иллюстрации; принятие владельцем — 1 октября 2026.
Изображения созданы генератором и проверены владельцем в нескольких локальных
раундах. Последняя версия «Мёртвого жука» содержит три фазы.

`manifest.json` связывает каждое упражнение с исходным PNG, его SHA-256,
полным WebP и миниатюрой исходной фазы. Исходные файлы и комментарии остаются
в локальном `artifacts/`; в runtime публикуются только выбранные версии.
Имена содержат номер, каталожный идентификатор и отпечаток исходника.

Полная иллюстрация использует `image_url`; производная миниатюра —
`thumbnail_url`. Существующие GIF используют независимый `animation_url` и
свою атрибуцию. Каталожный `ds:<id>` здесь служит ключом сопоставления,
а не обозначает авторство новых изображений.
