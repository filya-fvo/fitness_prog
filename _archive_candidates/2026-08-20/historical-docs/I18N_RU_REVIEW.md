## Как заполнять

| Значение в «Принято» | Смысл |
|---|---|
| `да` | Берём предложенный русский |
| `нет` | Не трогать (оставить английский) |
| свой текст | Использовать твой вариант вместо предложенного |

## Где встречается (справка, не для заполнения)

| Англоязычное | Где в UI / данных |
|---|---|
| Streak / Streak тренировок | Главная, Прогресс, бейджи |
| Full body / Full body A/B / PPL / Custom | Типы программ (Профиль, Программы) |
| Upper 40′ / Full body 30′ / FB… | Быстрые пресеты каталога тренировок |
| AI-тренер / AI: замена | Чат, активная тренировка |
| RIR | Подзаголовок активной тренировки (`RIR 2` и т.п.) |
| RPE | Внутреннее поле завершения (если где-то светится подписью) |
| Gym visual | Кредит на анимации упражнения |
| account | Shell: `… · account` без username |
| Admin labels (beginner/youtube/…) | Только админка |
| resistance band | Каталог упражнений (`equipment`) |
| Каденс / Темп /500м | Параметры кардио-тренажёра в модалке подхода |
