## 0.9.0 — 2026-08-03

### Тренировки / UX
- **Разминка** перед основной частью: зал = кардио (~5 мин, тренажёр+параметры запоминаются) + мобильность; дом/улица = короткая мобильность 3–5 мин. Можно пропустить всю разминку или отдельные шаги.
- **Ввод подхода**: кнопка «Добавить подход» + wheel (повторы/кг или мин/сек), примечание по желанию, ручной таймер.
- **Типы нагрузки** упражнений: weight_reps / reps_only / timed / cardio_machine (эвристика по имени/мышцам/тегам).
- **Таймер отдыха** → уведомление в Telegram-бота (даже если Mini App открыт), с текстом про текущее/следующее упражнение.
- **Главная**: split-кнопка «Начать сегодня | ▾» — выбор дня программы и недели (лёгкая/средняя/тяжёлая).
- **Прогрессия недели**: после полного круга сплита light→medium→heavy→light…; ручной выбор сохраняется в `users.goals`.
- Рекомендуемый вес/время — **с прошлого раза** (фаза недели влияет на цель/RIR, не переписывает префилл).

### API
- `POST /programs/{id}/start` принимает `week_phase`.
- `POST /notifications/timer-ended` — мгновенный ping в бота.

### Docs
- USER_GUIDE, programs-matrix, NOTIFICATIONS обновлены.

## Как обновлять этот файл

После каждой порции правок по запросу пользователя:

1. Поднять patch/minor в заголовке (или добавить секцию под текущей версией, если ещё не релиз).
2. 3–10 буллетов: что изменилось для пользователя/агента.
3. Указать пути ключевых файлов при необходимости.
4. Синхронно обновить `version` в `backend/app/main.py` (FastAPI) при minor+.
