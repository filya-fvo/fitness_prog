# Сверка интерфейса с утверждённым референсом — 2026-09-25

Состояние кода: локальный `d6527fa`. Референсы: [пять основных экранов](superpowers/specs/assets/2026-09-24-root-navigation-reference.png) и [внутренние экраны](superpowers/specs/assets/2026-09-24-internal-modules-reference.png). Это список работ для продолжения, **не** подтверждение готовности дизайна или production. Сверены изображения референса, текущие компоненты и доступные снимки; часть сохранённых E2E-снимков старше последних коммитов, поэтому не считается доказательством текущего вида. Для окончательной приёмки нужна новая мобильная съёмка тёмной и светлой темы.

## Что уже соответствует направлению

- Пять корневых разделов и их названия совпадают с референсом: Главная, Упражнения, Дневник, Помощь, Профиль (`navigation.ts`). Их не следует переименовывать.
- Тёмные токены, градиент оранжевый → розовый → фиолетовый и отдельный цвет успеха введены в `index.css`. Это основа, а не повод перекрашивать всё заново.
- Сон, вода и шаги уже разделены на три входные карточки; редактор сохраняет переход по датам (`DailyActivityCards`, `DailyActivityEditor`).
- Режимы «Основное» и «Расширенно» сейчас выбирают разные наборы секций (`personalDashboard.ts`, `ProgressPage.tsx`). Не возвращать прежнюю одинаковую аналитику.
- В деталях упражнения уже есть вкладки «Фото / Анимация / Видео», а отсутствие видео обозначено отдельно (`ExerciseMediaTabs`, `ExerciseMediaPlayer`).

## Порядок следующей работы

1. Сверстать **один** настоящий анатомический силуэт, показать/проверить его на мобильной плитке рядом с референсом, затем последовательно заменить весь набор мышц. Каждый готовый актив сразу использовать в каталоге и программах, тестировать и коммитить.
2. Исправить маршрут локального PNG во вкладке «Фото», затем провести поимённую проверку медиа. Для упражнений без исходного медиа готовить изображение лишь после проверки техники; для всех остальных сохранить связь с существующим GIF.
3. Перестроить плотность списка упражнений и карточку программы без изменения поиска, выбора, избранного и маршрутов.
4. По очереди довести Главную, Дневник/активность, Помощь и Профиль; затем формы, которых нет на референсе, по общим токенам.
5. Для каждого шага: снимки 320/393/1440 px (тёмная и светлая тема), визуальное сравнение, целевые тесты, lint/build/bundle и отдельный локальный commit. Не публиковать production до общей локальной приёмки.
