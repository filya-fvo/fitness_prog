# Проверка оформления «Помощь и FAQ» — 2026-10-02

Оформление принято владельцем; выпуск в production разрешён 2026-10-02.
Ниже зафиксированы проверки подготовленной версии перед выпуском.

## Что изменено

- Карточки, поиск и тематические фильтры используют существующие токены палитры
  и общие поверхности приложения. Активный фильтр выделен рамкой и насыщенностью текста.
- Для каждого из 31 материалов создана собственная векторная сцена: график,
  камера, календарь, вода, питание, таймер, гантели и другие предметы по теме ответа.
  Иллюстрация находится рядом с заголовком, описание и пункты имеют отдельное место.
- Убраны конфликтующие старые стили карточек маршрута `/knowledge`. Его фотографическая
  обложка сохранена. `/faq`, `/help` и `/knowledge` используют один компонент ответа.
- Добавлены стрелка раскрытия и явный фокус клавиатуры. Сохранены нативные `details`,
  поиск, фильтры, переход к конкретному ответу, поддержка и возврат в приложение.
- SVG-сцены находятся в отдельном ассете Vite с хэшем в имени; новых зависимостей нет.

## Выполненные проверки

- `npm run lint`: без ошибок и предупреждений.
- `npm run build`: TypeScript и production-сборка успешны в `.dist-check`.
- `npm run check:bundle`: общий JS gzip 551 098 байт при лимите 553 000;
  продуктовый JS gzip 495 293 при лимите 497 000. SVG отдельно: 10,48 kB, gzip 2,25 kB.
- `faq-design.spec.ts`, `faq.spec.ts`, `accessibility.spec.ts`: 37 passed,
  4 skipped (desktop 1440 px в двух мобильных профилях).
- Матрица: 320 × 568, 375 × 844, 393 × 844, 1440 × 844; светлая и тёмная тема;
  Chromium, Android Chrome/Pixel 7, iPhone WebKit/iPhone 13. Все 31 иллюстрации
  загружаются, заголовки не пересекаются с ними, горизонтального переполнения нет.
- Проверены раскрытие и сворачивание с Enter, поиск, фильтр питания,
  равная ширина категорий, deep link с фокусом и возврат в приложение.
- Axe не нашёл serious/critical нарушений на публичных маршрутах; дополнительно
  проверены обе темы FAQ при 393 px.
- `faqSearch.test.ts`: 4 unit-теста поиска прошли.
- Три визуальных эталона `/faq`, `/help`, `/knowledge` обновлены на Windows
  после просмотра; обычный запуск сравнения без обновления: 3 passed.
- Повторная проверка перед выпуском: 29 passed, 4 skipped (FAQ и визуальные эталоны).
- Первый полный CI-прогон: 179 passed, 8 skipped, один сбой теста загрузки
  админки. Воспроизведено локально: запрос возвращал ошибку через 250 ms до
  завершения навигации, поэтому индикатор уже исчезал. В тесте ответ удерживается
  до проверки загрузки, как в существующем тесте журнала аудита. Runtime-код не
  менялся. После исправления: 5 повторов с двумя workers и ESLint прошли.
