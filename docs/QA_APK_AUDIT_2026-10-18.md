# Последовательное исправление C2 — 18.10.2026

## Воспроизведение

После выпуска APK18 продолжен один дефект: POST создания своего продукта ещё
выполняется, пользователь закрывает окно кнопкой или Escape, снова открывает
его в том же аккаунте/дне и меняет поля. Старый успех закрывал новое окно,
очищал его поля и выбирал прежний продукт; старая ошибка попадала в новый
черновик. Смена owner/day и уход со страницы уже были защищены и повторно
не разрабатывались.

Четыре реальные browser-регрессии (success/error × button/Escape) дали RED4:
два исчезнувших окна, две ошибки прежней попытки. Стенд использовал только
фикстуры; реальные пользовательские записи не читались и не менялись.

## Причина и правка

Scope дневника не менялся при закрытии формы. DailyLog теперь отдельно
отслеживает версию окна создания; кнопка и Escape используют единый обработчик
закрытия. Success/error применяются только к версии, отправившей запрос.
Фактический результат создания по-прежнему инвалидирует кэш каталога.

Общий saving остаётся занят до завершения запроса. Его finally освобождает
отправку по прежней проверке owner/day; проверка версии здесь намеренно не
нужна, иначе новый черновик остался бы заблокирован. Нового POST до завершения
предыдущего нет. Существующий серверный продукт не удаляется и не создаётся
повторно ради обновления интерфейса.
