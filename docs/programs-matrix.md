# Матрица тренировочных программ (v2)

## Оси подбора

| Ось | Значения | Где хранится |
|-----|----------|--------------|
| Пол | `male` / `female` | `structure.sex[]` + `anthropometry.sex` |
| Место | `home` / `gym` / `outdoor` | `structure.location` + `goals.location` |
| Инвентарь | `bodyweight`, `bands`, `dumbbells`, `barbell`, `machines` | `structure.equipment[]` + `goals.equipment[]` |
| Уровень | `beginner` / `intermediate` / `advanced` | `level` / `target_level` + `goals.level` |
| Суставы | `no_knee`, `no_spine`, `shoulder_sensitive` | `structure.limitations[]` + `goals.limitations[]` |

## Правила контента

1. **Зал / улица:** в `schedule` только рабочие упражнения. Разминка 5–8 мин — вне списка.
2. **Дом:** можно чуть больше контроля корпуса, но без «мобилити-дня» как замены силовой.
3. Имена упражнений **строго** из `exercises.json` / БД (`name_ru`).
4. `no_knee`: без приседов, выпадов, прыжков, жима ногами с глубоким сгибом — упор на upper + hinge/glute machine + leg curl.
5. `no_spine`: без становой, тяг в наклоне, гиперэкстензии — машины, жимы, вертикальные/горизонтальные блоки сидя, glute bridge.
6. `shoulder_sensitive`: щадящий, а не «нулевой» профиль нагрузки. Без жимов и тяг верхней части тела, отжиманий, подтягиваний, упоров на руки и движений над головой; основа — ноги, ягодицы, икры, кор и изоляция рук у корпуса.
7. В одном рабочем дне должно быть **6–7 упражнений** без дублей: основные движения идут первыми, изоляция и кор — после них.
8. Объём увеличивается только за счёт недостающего двигательного паттерна или мышечной группы; разминочные упражнения не используются как наполнитель.

## Методическая основа новых схем

- [ACSM Position Stand 2026](https://pubmed.ncbi.nlm.nih.gov/41843416/): основные мышечные группы рекомендуется тренировать не реже двух раз в неделю; для силы приоритетны тяжёлые многосуставные подходы в начале занятия, для гипертрофии — достаточный недельный объём.
- [Метаанализ Split и Full Body 2024](https://pubmed.ncbi.nlm.nih.gov/38595233/): при равном недельном объёме формат распределения тренировок сам по себе не даёт устойчивого преимущества, поэтому каталог предлагает несколько расписаний под разную доступность пользователя.
- [Мета-регрессия объёма и частоты 2026](https://pubmed.ncbi.nlm.nih.gov/41343037/): рост объёма связан с дополнительным эффектом с убывающей отдачей; частота используется прежде всего для удобного распределения рабочих подходов и восстановления.

Это шаблоны для здоровых пользователей, а не индивидуальное медицинское назначение. Техника, запас повторов и восстановление приоритетнее формального выполнения заданного объёма.

## Подбор на фронте

`frontend/src/utils/programRecommend.ts`:

- жёстко режет чужой пол;
- сильно бустит совпадение `location` и `limitations`;
- штрафует программы с инвентарём, которого нет у пользователя;
- учитывает цель / уровень / дни в неделю;
- не поднимает вариант с другой недельной частотой над точным совпадением, если
  остальные обязательные параметры совместимы.

### Уточнение зальных программ `no_knee` — 2026-08-20

- В рабочих упражнениях на ноги не используется обычный ягодичный мост без веса.
- Женский шаблон распределяет варианты по дням: мост со штангой + отведение ноги
  в кроссовере; румынская тяга + мост с гантелью; тяга каната между ног + сгибание ног.
- Гакк-приседания и разгибания ног остаются в общем каталоге, но исключены из
  `no_knee` как коленодоминантные движения.
- Каталог содержит 128 упражнений; добавлены cable pull-through, cable hip
  extension, reverse hyper и мост с гантелью.

Новые парные шаблоны для мужчин и женщин:

- опытный: антагонисты 3 дня, Тяни/Жми 4 дня, только тренажёры 4 дня;
- продвинутый: пятидневный сплит с двойной частотой, четырёхдневное чередование акцентов, Powerbuilding 4 дня;
- новичок: Full Body 2 дня как минимальный устойчивый график.

Мужская и женская карточки одной схемы используют одинаковые движения и объём: пол остаётся осью подбора для совместимости с текущей анкетой, но нагрузка определяется уровнем, целью и восстановлением.


## Разминка в приложении (runtime)

Не хранится в `schedule` программы — собирается на клиенте при старте:

| Место | Состав | Длительность |
|-------|--------|--------------|
| `gym` | Кардио (тренажёр, по умолчанию беговая) + мобильность без отягощений | ~10 мин (кардио ~5) |
| `home` / `outdoor` | Только мобильность | 3–5 мин |

- Пропуск: вся разминка или отдельные шаги.
- Логируется предпочтение **кардио** (exercise id, duration, machine params) в `users.goals`.
- Неделя нагрузки light/medium/heavy: override при старте + авто-сдвиг после полного круга сплита.
