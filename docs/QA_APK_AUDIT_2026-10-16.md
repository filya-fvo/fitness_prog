## E5: что доказано

Старый FATAL сохранён: Chrome_IOThread, dangling raw_ptr/Unretained,
WebView BuildId `3fed08901ee0e6620bf486e4e9e34fba0a577d62`.
Причина и необходимый триггер не установлены.
Владелец 16.10 подтвердил, что самопроизвольного закрытия FilFit на POCO
не замечал. Наблюдаемый E5 относится к сохранённому автоматическому запуску;
его нельзя выдавать за подтверждённый сбой на телефоне.

1. Minimal-host `be767f3`: actual tests 1, skip 0, все 20 фаз, тот же BuildId,
   **NONREPRODUCTION**. Каталог доказательств:
   `artifacts/android-priorities-20261009/webview-e5-be767f3-wait-runtime-20261016_213417`.
2. Полный продуктовый APK `a97c179`: исходный mandatory-метод
   `NativeBridgeReplyProxyTest#modern_reply_proxy_is_bound_before_dispatch_after_navigation`,
   actual tests 1, skip 0, все 14 фаз, тот же BuildId,
   **NONREPRODUCTION**. Каталог:
   `artifacts/android-priorities-20261009/webview-e5-product-cached-runtime-20261016_214724`.

Два других запуска остановились до instrumentation: передача 273 МБ provider APK
через ADB возвращала exit 0 с обрезанным файлом. Строгие SHA-проверки сохранили FAIL.
Продуктовый валидный запуск использовал полную копию из первого валидного стенда:
её host SHA совпал с SHA установленного файла нового AVD до и после проверки.
Assertions исходного теста, BuildId guard и обязательные фазы не ослаблялись.

Для обоих валидных запусков cleanup: portsFree=true, cleanupErrors=[].
OpenVPN и общий ADB не останавливались. Старые AVD/БД/отчёты сохранены.

## Незавершённое

- E5 нельзя объявлять исправленным на основании двух успешных запусков.
  Следующее причинное исправление требует воспроизводимого FATAL и фазы его
  появления. Гипотеза worker-thread reply не признана доказанной причиной.
- Эти проверки не заменяют полный installed signed-in nutrition/offline цикл
  новой сборки, всю API24/API36 матрицу и реальный POCO/камеру/OCR/PIN/HyperOS.
- Перед публичным выпуском нужна точная original-key сборка штатным publisher,
  применимые release gates и backup/restore VPS по runbook. Публикация и
  production seed/reset в этом аудите не выполнялись.
