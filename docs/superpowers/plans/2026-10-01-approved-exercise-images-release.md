# Публикация принятых изображений упражнений

Разрешение владельца: применить все принятые изображения в production; в карточке показывать полный файл, в миниатюре только исходную фазу. Последний трёхфазный «Мёртвый жук» также принят сообщением «отлично».

1. Собрать последние принятые версии 134 упражнений из локальных раундов проверки. Сохранить исходники; экспортировать полные WebP и миниатюры первой фазы с версионированными именами и проверяемым manifest.
2. Добавить отдельное необязательное поле `image_url` в модель и API. «Фото» использует полный файл с сохранением пропорций; списки используют `thumbnail_url`. Существующие GIF и видео остаются самостоятельными материалами.
3. Обновить seed и сохранение изображений при пересборке каталога. Применить append-only SQL migration без изменения UUID, тренировок или пользовательских данных; сохранить прежние атрибуции GIF отдельно от новых изображений.
4. Проверить контракт API, полное изображение в карточке, первую фазу всех миниатюр, каталог, миграции, backend и frontend. Подготовить scoped commit, исключив посторонние изменения рабочего каталога.
5. Push production-ветки; резервная копия VPS; ff-only pull, миграции и сборка/запуск Compose. Проверить оба публичных домена, все новые файлы и ссылки в production-каталоге.
