## Проверки и ограничения

- Прочитан полный `AGENTS.md`; дополнительных `AGENTS.md` в проекте не найдено.
- Входящие ссылки проверены поиском точного имени по коду, скриптам и документации; derived Graphify snapshot и результаты обзоров не использовались как источник активных требований.
- Доказательства temporary-профилей подтверждены исполняемым `frontend/scripts/lighthouse-audit.mjs`; runtime-сборка отделена от проверочной по Vite, publish script и `AGENTS.md`.
- После удаления подтверждено отсутствие каждого из десяти точных путей. Git diff этой части содержит только три перечисленных архивных удаления и новый отчёт.
- Кодовые проверки общего аудита выполняются отдельно; эта очистка не меняет поведение приложения и не требует нового теста.
- База PostgreSQL не является файлом проекта; Redis `tools/redis/dump.rdb` — runtime, он сохранён. Эта инвентаризация не оценивает внутреннее содержание backup/БД и не удаляет данные пользователя.
- Рекурсивная инвентаризация является снимком во время работающей общей сессии: параллельные тесты могут создавать новые отчёты и кэши. Объём освобождения подтверждён по удалённым путям, а не по разности общего размера проекта.
